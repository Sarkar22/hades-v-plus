# session.txt -- the scripted session of `make freertos-shell-test` (test/freertos/shell).
#
# The simulator's console bridge (sim/console.cpp) types every line that does not start
# with '#', each one after the shell has printed its prompt, and adds the Enter key (CR).
# Escapes: \r \n \t \e (ESC) \\ \xHH; \c at the end of a line suppresses the CR. Every
# typed line must produce exactly one new prompt.
#
# session.py then checks the transcript. Lines starting with "#?" hold a regular
# expression that must match one line of the output of the command typed just before
# (in the order given); "#!" one that must match none of them. The output does not
# include the command line itself as the shell echoes it after the prompt; "#>" holds a
# regular expression for that line. "#?dut", "#!dut", "#?golden" and "#!golden" (and
# "#>dut", "#>golden") apply only on that CPU (the golden CPU has no M, Zba, Zbb, Zbs,
# Zicntr, Zicond and branch predictor). Lines before the first typed line check the
# start-up banner.
#
