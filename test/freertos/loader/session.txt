# session.txt -- the scripted session of `make freertos-shell-test APP=loader` (test/freertos/loader,
# SPEC.md section 10.1); `make freertos-shell-compare APP=loader` runs it on both CPUs, and
# `make freertos-loader-test` and `make freertos-loader-compare` run it with session-ext.txt.
#
# The format is that of test/freertos/shell/session.txt: every line that does not start with
# '#' is typed, followed by Enter, after the shell's prompt; "#?" requires a line of the output
# of the typed line before it to match (in the given order), "#!" forbids one, "#>" checks the
# echoed command line; "#?dut" and "#?golden" apply to one CPU only. Two more kinds of lines
# belong to the typed line before them and are not typed lines themselves:
#   #< <file>   the console bridge sends the file when the program asks for one (load); the
#               file names are relative to the build directory of the SDK, test/freertos/sdk/
#   #: <text>   the bridge types the text and Enter (none if it ends in \c) when the program
#               waits for input (a running app)
# Every app is the RV32I build, so that the session runs on the golden CPU as well.
#

#? ^  apps: 'load' receives an app into the 128 KiB slot at 0x00060000, 'run' runs it$
